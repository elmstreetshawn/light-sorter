# Light Sorter

A Mac app that sorts folders of images from lightest to darkest.

**Download:** go to [Releases](../../releases/latest) and get the .dmg for your Mac.

Open the app, pick the folder that holds your image folders, and wait for "Done!".
Each folder gets a `sorted_light_to_dark` folder with numbered copies (001 = lightest).
Original files are never changed.
